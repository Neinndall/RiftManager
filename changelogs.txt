   * Fixed runtime BAML exceptions by standardizing resource paths (Pack URIs) and resource initialization order.

RiftManager | v1.0.0.4

# HOTFIX RELEASE
This hotfix addresses critical compatibility issues with the new Riot Games asset CDNs and improves the efficiency of event processing.

# IMPROVEMENTS
   * Improved catalog discovery: The system now dynamically builds paths using the comic number (e.g., comics-pipeline-4) and deploy hashes, ensuring full compatibility with new Riot folder structures.
   * Universal Audio Search: Implemented a deep search logic that finds audio clips anywhere in the JSON files, regardless of structure changes.
   * Intelligent Audio Routing: Voice lines, sound effects, and music are now automatically classified and downloaded to their correct Riot CDN folders (AudioLocales or SoundFX) based on clip suffixes.
   * Efficient Lazy Loading: Catalog scraping is now deferred until a specific comic is selected, improving initial load times and avoiding unnecessary network requests.
   * Enhanced Bundle Filtering: The system now uses the full event context (titles and navigation IDs) to ensure shared thematic bundles (like regional assets) are correctly identified and downloaded.

# BUG FIXES
   * Fixed a critical 404 error when attempting to fetch catalogs from outdated static paths like "/Comic/".
   * Fixed a bug where the system would reuse the catalog from the first comic found instead of the one specifically selected by the user.
   * Fixed an issue where the asset converter (BinToJson.exe) was failing due to incorrect command arguments and case-sensitive resource paths.
   * Fixed a filtering bug that caused shared thematic bundles to be skipped during specific comic extractions.
